# 策略组图标

订阅统一引用仓库中的 PNG。路径保留稳定文件名，便于多个客户端共享。

除 `china-ai.png` 外，图标基于 Tabler Icons v3.51.0 的线条图形，使用本仓库选定的配色和圆角底色，导出为 96 × 96 PNG。[Tabler Icons](https://github.com/tabler/tabler-icons/tree/v3.51.0) · [MIT 许可](../licenses/tabler-icons-MIT.txt)

`china-ai.png` 保留 Lobe Icons 的 DeepSeek 原图。[图标来源](https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-png/dark/deepseek-color.png) · [MIT 许可](../licenses/lobe-icons-MIT.txt)

品牌图形用于识别对应策略组。品牌名称和标识仍归各自权利人所有。
